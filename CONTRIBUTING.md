# Contribution

Ce dépôt est un outil d'étude et d'exécution contrôlée. Toute modification qui change une définition, une classification, un seuil ou une règle de décision doit :

1. expliquer la raison du changement ;
2. indiquer les données déjà observées au moment du changement ;
3. conserver la compatibilité avec les anciennes observations ou documenter la migration ;
4. ajouter ou modifier un test lorsque la règle est automatisable ;
5. éviter toute modification silencieuse d'une catégorie méthodologique.

Les changements purement ergonomiques peuvent suivre un cycle plus léger.
