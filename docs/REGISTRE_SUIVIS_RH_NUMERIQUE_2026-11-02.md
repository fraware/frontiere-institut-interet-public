## Protocole commun de clôture

1. Pour chaque suivi, enregistrer **la source, sa date, le périmètre, la conclusion exacte et les inconnues**.
2. Ne jamais confondre une politique annoncée avec son exécution, ni une mobilité observée avec un effet causal.
3. Pour les cas, conserver les événements datés, acteurs institutionnels, étapes bloquantes, alternatives et issue ; rechercher les cas négatifs.
4. Contrôler qu'un document RH nominatif n'est jamais versé au dépôt public.
5. Reporter les résultats consolidés dans `docs/ETAT_DU_PROJET.md` et le suivi de feuille de route uniquement une fois les vérifications réalisées.
