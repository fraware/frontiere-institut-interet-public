# Catégories communes pour les comparaisons

Afin de comparer plusieurs réponses sans dépendre de synonymes arbitraires, les exercices de développement utilisent les catégories ci-dessous.

## Formes de ressource

- personne ;
- équipe ;
- laboratoire ;
- organisme public ;
- prestataire ;
- réseau ;
- vivier ;
- formation ;
- infrastructure ;
- outil ou service ;
- donnée ou document.

## Voies de résolution

- capacité interne existante ;
- mobilisation d'un autre organisme public ;
- mission ponctuelle d'expertise ;
- équipe interne mutualisée ;
- coopération scientifique ;
- mobilité temporaire ;
- recrutement contractuel ;
- recrutement statutaire ;
- formation ou reconversion ;
- amélioration des conditions de rémunération ou de carrière ;
- achat d'une prestation ;
- investissement matériel ;
- mutualisation entre organisations ;
- réorganisation ;
- maintien du mécanisme existant ;
- aucune intervention supplémentaire.

Ces catégories servent uniquement à rendre les comparaisons cohérentes. Elles ne constituent pas une note attribuée à une personne ou à une organisation.
