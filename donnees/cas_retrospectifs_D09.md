# D09 — Combler une lacune critique d'observation météorologique

Source : S040.

Un département insulaire ne dispose pas d'un équipement d'observation météorologique présent ailleurs sur le territoire national.

Question : quelle réponse privilégier si le déficit principal vient d'une capacité matérielle absente ?

Réponse observée : installation programmée d'un radar météorologique.
