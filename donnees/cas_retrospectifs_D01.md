# D01 — Perte soudaine d'une capacité d'analyse de données

Source : S001.

Un petit opérateur public perd une compétence interne nécessaire à l'analyse de données financières. Le marché des profils spécialisés est tendu et les conditions salariales de l'établissement sont peu compétitives.

Question : quelles voies de résolution et quelles formes de ressource examiner pour rétablir une capacité utile rapidement puis durablement ?

Réponse observée dans les sources : recrutement de nouveaux agents spécialisés ; la résolution finale reste à documenter.
